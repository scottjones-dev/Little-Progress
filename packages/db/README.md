# @repo/db

Database layer: Drizzle ORM on PostgreSQL (node-postgres).

## Why it exists

Only the API talks to Postgres. This package owns the schema, migrations and the client so the data model lives in one place. It also exposes the care vocabulary lists (textures, reactions and so on) that the web and native apps import for their chips.

## What's inside

```
src/
  index.ts        db client (Pool + drizzle)
  vocab.ts        enum lists + types (no DB code, safe for web/native)
  schemas/        child, carer, food, entries (+ detail tables), attachments; auth.ts is generated
  migrations/     generated by drizzle-kit (never edit by hand)
drizzle.config.ts
```

Tables use `snake_case` columns and `uuidv7()` ids. Enum-like columns are `text` with check constraints. A family is the Better Auth `organization` (its ids are text), so every `family_id` column is `text` referencing `organization.id`. `schemas/auth.ts` is generated by `pnpm auth:generate` and must not be edited by hand.

## Use it

```ts
import { db } from "@repo/db";
import { child } from "@repo/db/schemas/family";

const children = await db.select().from(child);
```

```ts
import { reactions } from "@repo/db/vocab"; // safe in web and native
```

## Run it

Postgres runs in Docker: `pnpm infra:postgres:up`. All commands run through Infisical (`/api`, `DATABASE_URL`).

| Command (repo root) | Does |
| --- | --- |
| `pnpm db:generate` | create a migration from schema changes |
| `pnpm db:migrate` | apply migrations |
| `pnpm db:migrate:local` | same, without Infisical: reads the root `.env` (`pnpm setup:local`). Also `db:generate:local`, `db:check:local` and `dev:local` (Drizzle Studio) in this package |
| `pnpm db:push` | push schema directly (throwaway dev use) |
| `pnpm db:pull`, `db:export`, `db:check`, `db:up` | other drizzle-kit commands |
| `pnpm auth:generate` | regenerate `src/schemas/auth.ts` with the Better Auth CLI (never edit that file by hand) |
| `pnpm dev` | includes Drizzle Studio (<https://local.drizzle.studio>) |

## Tests

## Depends on / used by

Depends on `@repo/env`, `drizzle-orm`, `pg`, `drizzle-kit`. Used by `apps/api` (client and schemas); `apps/web` and `apps/native` use `@repo/db/vocab` only.
