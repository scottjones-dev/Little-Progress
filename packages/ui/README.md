# @repo/ui

The website's design system: shadcn/ui components, the Midnight Sanctuary theme (light and dark), and the helpers they share. **Web only.** The Expo app does not use this package; it has its own Nativewind styling in `apps/native` (see `docs/ui.md`).

## Why it exists

One place for the look and feel of the website: the same buttons, forms, dialogs and colours everywhere, written once. It is laid out the way shadcn's official monorepo template lays it out, so the shadcn CLI keeps working and updates are a command, not a merge.

## What's inside

| Path | What it is |
| --- | --- |
| `src/components/*.tsx` | the shadcn components (65). Generated by the shadcn CLI: do not hand-edit, re-add or update them with the CLI (they are excluded from lint for that reason) |
| `src/styles/globals.css` | Tailwind setup and the theme: colours for light and dark, radius, and the font variables |
| `src/lib/utils.ts` | `cn()`, joins class names (every component uses it) |
| `src/hooks/use-mobile.ts` | `useIsMobile()`, used by the sidebar |
| `postcss.config.mjs` | the PostCSS config the website re-exports |

Imports go through the package's `exports`:

```tsx
import "@repo/ui/globals.css"; // once, in the website's root layout
import { Button } from "@repo/ui/components/button";
import { cn } from "@repo/ui/lib/utils";
```

## Use it

The website (`apps/web`) already depends on it, compiles its source (`transpilePackages` in `next.config.ts`) and wraps the app in the providers it needs (`ThemeProvider`, `TooltipProvider`, `Toaster` in `src/app/layout.tsx`). To use a component, import it and use it as it is: the components own their typography and spacing, and the project's shadcn lint rules flag restyling them (add a variant in the component instead, when the design calls for it).

### Add or update a component

Run the shadcn CLI from the website, which reads `apps/web/components.json`:

```bash
cd apps/web
pnpm dlx shadcn@latest add dropdown-menu
```

Files land in `packages/ui/src/components` and any new libraries are installed into this package. Check that `pnpm check-types` and `pnpm test` still pass, and that new libraries are in `packages/ui/package.json`, not the website's.

## The theme

Dark is the brand: its colours are the ones in `packages/config/src/app.ts`, and a test fails if the stylesheet drifts from them. Light is a warm off-white with a darker gold. Tests also check that every text pair is at least 4.5:1 and every control border and chart colour at least 3:1, in both themes. Details and the reasoning: `docs/ui.md`.

## Tests

`pnpm --filter @repo/ui test`: brand colours match `@repo/config` and the native app's tokens, contrast in both themes, and the package's export paths exist. Type check: `pnpm --filter @repo/ui check-types`.

## Depends on / used by

Depends on Radix (`radix-ui`), `lucide-react`, `class-variance-authority`, `cn`, `next-themes`, `sonner`, `recharts` and the other libraries the components need, plus `tailwindcss` and `tw-animate-css`. Used by `apps/web` only.
